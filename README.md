## Auto Share

Auto Share is a Minecraft mod that allows the owner of a local network world to automatically distribute resource packs to everyone else, eliminating the need for each player to download and install them manually.

## Usage

* One player (the host) specifies a direct link to the ZIP archive containing the resource pack in the mod's config.
* As soon as other players connect to the local world, the mod offers to automatically download the resource packs in the background and applies them.
* No manual downloads, folder transfers, or game restarts—everything happens on the fly.

## Information for world owners

* The link must be to a ZIP file. On most websites, simply copying the link to the download button is sufficient. Examples of obtaining links for Modrinth and CurseForge.
